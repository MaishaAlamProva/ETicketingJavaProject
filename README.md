========================================
        E-Ticketing Java Project
========================================

A desktop-based electronic ticketing system built with Java, focusing on a modular architecture, secure authentication, and a user-friendly Graphical User Interface (GUI).

========================================
💼 PROJECT HIGHLIGHT
========================================

E-Ticketing System: Secure N-Tier Architecture

Developed a Java-based system focusing on secure authentication and access control. Leveraged N-tier architecture to decouple the Data Access Layer (DAL) and ensure secure data handling.

========================================
🚀 GETTING STARTED
========================================

This project serves as the entry point for an E-Ticketing management application. It initializes the system by launching the main login portal.


========================================
🏗️ ARCHITECTURE
========================================

The project is organized into several packages to ensure a separation of concerns:

• UI  
  Contains the Swing-based graphical components  
  (e.g., LoginForm, Registration)

• Services  
  Handles the business logic and communication  
  between the UI and Data Access Layer

• Model  
  Defines the data structures and entities  
  (e.g., User)

• DAL (Data Access Layer)  
  Manages data persistence and database interactions

========================================
🛠️ PROJECT STRUCTURE
========================================

• Start.java  
  The main class that triggers the application.  
  It instantiates the LoginForm and makes it visible to the user.

• Start.class  
  The compiled bytecode of the entry class.

• User Management  
  Includes logic for user registration and secure handling  
  of user information such as First Name, Last Name,  
  Username, Phone Number, and Password.


========================================
📌 FEATURES
========================================

• Secure Authentication System  
• User Registration and Access Control  
• Layered N-Tier Architecture  
• Modular Java Swing GUI  
• Secure Data Handling with DAL  
• Ticket Booking System (Planned)
